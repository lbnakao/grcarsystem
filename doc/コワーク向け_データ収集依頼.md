# 【作業依頼】予約システム（コアキャスト／アイパス）からのデータ書き出し調査

宛先：Cowork（ブラウザ自動操作エージェント）
作成：開発担当より

---

## 0. 前提・あなたの役割
- ユーザーは **コアキャスト** と **アイパス**（どちらも宿泊施設の予約管理システム）に **すでにログインできる状態** です。
- あなたの役割：両システムの中を操作して、**①必要なレポートがどこにあるか ②それをCSV/Excelで「書き出し（ダウンロード）」できるか ③その中身（項目）** を調べ、**実ファイルを書き出して保存**し、**メモにまとめる**ことです。
- ⚠ **読み取り・書き出しのみ**。設定変更・予約データの編集・削除は絶対にしないでください。

## 1. 背景（何のためか）
グローバルリゾートの「全体売上収支」をWeb管理システム化し、**Excel手入力をやめる**プロジェクトです。
今は各施設の売上・経費・稼働などを手入力していますが、その元データは予約システムにあります。
**予約システムからCSV等で書き出せれば、手入力をやめて自動取込にできる** ── それを確認するのが今回の目的です。

## 2. 対象システムと施設
| システム | 対象施設 |
|---|---|
| **コアキャスト** | デルーネ、弥山、ビュー |
| **アイパス** | 本川、温井、いこいの村、周防大島 |

## 3. ほしい数字（最終的にシステムへ入れる項目）
施設ごと・**月別（できれば日別）**に、次の数字の元になるレポートを探してください：
- 販売客室数（販売した部屋数）
- 利用人数（宿泊人数）
- 客室売上（部屋の売上金額）
- **食事売上（または食事人数）** ← ここが手作業の山。重点的に。
- 稼働率
- 客室単価（ADR）／客単価

## 4. 具体的にやってほしいこと

### コアキャスト
1. **「日別 売上／ADR／稼働率レポート」**にあたる画面を探す（部屋数・利用人数・客室売上・稼働率・ADRが出る画面）。
2. その画面に **CSV／Excelダウンロード（書き出し）ボタンがあるか** 確認。
3. あれば、**直近の締まっている1ヶ月分（例：2026年5月）を書き出して保存**。可能なら4月分も。
4. **食事（食事人数・食事売上）** が分かる画面・項目を探す。コアキャストから食事人数を取って別Excelで計算している、とのこと。その「食事人数」が出る画面を特定し、あれば書き出す。
5. 画面のスクショ（レポート画面・書き出しボタン・書き出し設定）を撮る。

### アイパス
1. コアキャスト同様、**売上・稼働・客室数・利用人数が分かるレポート画面**を探す。
2. **CSV／Excel書き出しの可否**を確認し、あれば直近1ヶ月分（例：2026年5月）を書き出して保存。
3. 食事に関する項目があるかも確認。
4. スクショを撮る。

- スクショも同じフォルダに `画面_(説明).png` の名前で保存してください。

## 6. 調査メモ（これも保存してほしい）
各フォルダに **`調査メモ.txt`** を作り、次を箇条書きで書いてください：
- レポートはどのメニュー階層にあったか（例：メニュー＞分析＞日別レポート）
- 書き出しは **できたか／できなかったか**。できた場合の **形式（CSV/Excel/PDF）** と **ファイル名**
- 書き出しに含まれる **項目（列名）の一覧**（例：日付、室数、人数、室料、食事…）
- **食事データ**は取れたか／どこにあったか
- うまくいかなかった点・ログインや権限で詰まった点

## 7. 完了の合図
上記が終わったら、「コアキャスト・アイパス・食事集計の各フォルダに、書き出しファイル＋スクショ＋調査メモを保存した」と報告してください。
→ そのファイル群を開発担当（私）が受け取り、**自動取込機能の設計・実装**に使います。
